# Class 10 Revision Cards

Revision cards for CBSE Class 10 Maths and Science.

The page has these decks:

- **Physics & Bio twins**: pairs of concepts that are easy to mix up.
- **Maths rules**: formulas and conditions that MCQs test.
- **Equation bank**: 26 balanced chemical equations.
- **Chemistry facts**: gas tests, indicators, pH, and salts.
- **Proof order**: tap the steps of a proof in the right order.
- **Reading drill**: tap the words that change what a question asks.
- **Exam-day card**: a routine to follow in every exam.

Progress is saved in the browser you use, so use the same device and browser each time.

The site is a single `index.html` file with no build step.
